# sheriffmotos.com

Sitio informativo de la marca SHERIFF.

- Modelos y fichas técnicas: `data/modelos.json`
- Estilos: `src/site.css`
- Fotos: `public/img/modelos/<slug>/*.webp`
- Generar: `pip install jinja2 && python3 build.py` → carpeta `public`

Cloudflare Pages: comando de compilación `pip install jinja2 && python3 build.py`, directorio de salida `public`.
